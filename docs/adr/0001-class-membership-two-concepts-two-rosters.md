# ADR-0001: 반 소속은 두 개념, 반 명단은 두 종류

- 상태: 채택
- 날짜: 2026-10-27

## 배경

'학생의 현재 반'을 정하는 방식이 다섯 가지, '반 명단'을 정하는 방식이 네 가지였습니다. 어떤 곳은 배정 상태(`현재`)를, 어떤 곳은 날짜(배정 기간)를 봐서 결과가 서로 달랐습니다.

예를 들어 다음 주 날짜로 반을 옮기면, 반 목록과 반 상세의 인원이 달랐습니다. 반 배정 창에서는 학생이 어느 반에서 옮기는지도 알 수 없었습니다.

휴원생 처리도 호출하는 쪽마다 달랐습니다. 여섯 곳은 휴원생을 걸러 냈고, 세 곳은 그대로 셌습니다.

## 결정

반 배정 조회는 `src/02_Assignments.js` 한 곳에서 답하고, 정의는 `GLOSSARY.md`를 따릅니다. 그중 아래 둘은 **일부러 따로 둡니다.**

1. **다니는 반**(날짜 기준)과 **열린 정규 배정**(쓰기 대상)
   - 화면이 보여 주는 소속은 날짜 기준입니다.
   - 옮기기, 빼기, 시작일 변경의 대상은 아직 끝나지 않은 정규 배정입니다. 미래에 시작하는 배정도 포함합니다.
   - 미래 날짜로 이동한 학생은 이동일 전까지 예전 반을 다닙니다. 그래도 다음 이동이나 빼기의 대상은 새 반 배정입니다.
2. **반 구성원**(휴원 포함)과 **수업 기록 대상**(휴원 제외)
   - 반 목록 인원은 휴원생을 포함합니다. 휴원생도 반 소속이기 때문입니다.
   - 수업 기록, 숙제, 보고서, 계획, 반 개요·통계는 휴원생을 뺍니다.

## 결과

- 정의가 하나 남은 게 아니라 이름 붙은 두 개씩 남습니다. 앞으로 "정의가 두 개니 하나로 합치자"는 제안은 이 ADR을 먼저 확인해야 합니다. 두 질문은 서로 다른 질문입니다.
- 휴원생은 반 개요, 진도·숙제 기록, 반 통계 숫자에서 빠집니다. 반 목록 인원에는 남습니다.
- 쓰기 경로(배정 기간 변경과 시험대비 연동)도 다음 단계에서 같은 module 뒤로 옮깁니다.
